# Calculator

A simple calculator project built using **HTML, CSS, and JavaScript**.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear button
* Simple and user-friendly interface

## Technologies Used

* HTML
* CSS
* JavaScript

## About

This is a beginner-level project created to practice the basics of web development and JavaScript.

## How to Use

Open `index.html` in a web browser and use the calculator.
